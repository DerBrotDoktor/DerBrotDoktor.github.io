Final Thesis: Enhanced Editor

Unity · C#

May 2025 GitHub

For my final thesis at the S4G School for Games, I worked on developing prototype Unity asset packs aimed at improving the editor workflow for developers.

About the Project

The goal of my thesis was to create Unity Editor extensions that improve the user interface and make workflows more efficient and enjoyable for developers. I explored how visual and structural UI enhancements can increase clarity and usability.

The Project

This project was my final thesis at the S4G School for Games. I worked on it over the course of 10 weeks.

Tools

Development:

  • Unity (6)
  • GitHub Desktop

Management:

  • Miro
  • Google Workspace

Responsibilities

As the sole developer, I was responsible for implementing all Unity Editor extensions. This included researching editor functionalities, designing new workflows, and programming features in C#. I also focused on making the tools intuitive and user-friendly, ensuring they supported efficient project management and daily work for developers.

Solution

You can view and download the source files here.

Hierarchy
The Hierarchy package is a Unity Editor extension that improves the organization and visibility of GameObjects in the Hierarchy window. It adds useful visual indicators, customization options, and tools to make working with complex scenes more manageable.

Inspector
The Inspector package is a Unity Editor extension that provides additional attributes for organizing the Inspector.

Project
The Project package is a Unity Editor extension that improves the organization and clarity of folders in the Project window. It adds visual enhancements and customization options to make managing large or complex projects easier and more efficient.

Dictionary
The Serializable Dictionary package is a Unity Editor extension that allows you to view and edit dictionaries in the Inspector.

Learnings

One of the most valuable lessons I took from this project was learning how to approach tool development from the perspective of other developers. Instead of just writing code that "works," I had to think carefully about usability, clarity, and how even small design choices in the editor can affect a team's productivity.

I also deepened my understanding of Unity’s editor scripting API and improved my ability to create clean, modular systems that can easily be expanded in the future. Beyond the technical side, this project helped me improve my ability to plan and structure a larger solo project, set clear goals, and follow through with consistent progress over time.
